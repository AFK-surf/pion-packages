# `cookie` (v0.1.0)

Pure Pion **RFC 6265bis** HTTP Cookie, **CHIPS** (Cookies Having Independent Partitioned State), and embedded **Mozilla Public Suffix List (PSL)** library — 100% pure Pion, zero external dependencies, zero `extern "C"`, zero `World` dependency, and zero mutable module globals.

## Features

- **RFC 6265bis `Set-Cookie` Parsing & Formatting (`src/parse.pion`, `src/date.pion`)**:
  - Full RFC 6265 §5.1.1 cookie-date parser (`parse_cookie_date`) supporting IMF-fixdate, RFC 850, ANSI C asctime, flexible delimiters, 2-digit/4-digit years (`00..69 -> 2000..2069`, `70..99 -> 1970..1999`), leap years, `< 1601` rejection, and O(1) `Int64` civil calendar arithmetic (`format_cookie_date`, clamped to `1601..9999` per RFC 6265bis §5.6.1).
  - Full attribute parsing: `Expires`, `Max-Age` (takes precedence over `Expires`, `<= 0` immediate expiry, overflow clamping), `Domain` (at most one leading `.` stripped, lowercased, IP literal handling), `Path` (default-path §5.1.4; invalid later `Path` resets to default-path per §5.6.4), `Secure`, `HttpOnly`, `SameSite` (`Strict` / `Lax` / `None`; unknown values reset to `Default` per §5.6.7), `Partitioned` (parsed as a boolean attribute; `CookieJar` enforces CHIPS §2 `Secure` requirement).
  - Cookie name prefix enforcement (`validate_cookie_prefixes`, case-insensitive per RFC 6265bis §4.1.3 / §5.6 / §5.7 step 22): `__Secure-`, `__Host-`, `__Http-`, and `__Host-Http-` (including nameless-cookie value prefix checks).
  - Defensive parsing: 4096 B name+value size limit, 1024 B attribute limit, control character rejection (`0x00..=0x08`, `0x0A..=0x1F`, `0x7F`; `0x09` HTAB allowed), last-wins duplicate attributes, quoted-string values, nameless cookies (no `=`), WHATWG-aligned `parse_request_url` (`\` path separator for special schemes), and injection-safe `format_set_cookie` / `parse_cookie_header` / `format_cookie_header`.
- **Embedded Read-Only Mozilla Public Suffix List (`src/psl.pion`, `src/psl_data.pion`, `src/psl_index.pion`)**:
  - Complete official Mozilla PSL snapshot `@763a4c200052` (2026-11-23; **10,472** rules: **6,950** ICANN + **3,522** Private) stored as a sorted immutable string literal (**167.9 KiB**) paired with a compact read-only node-flag index (reproducibly generated by `packages/cookie/scripts/gen_psl_index.py`) for zero startup allocation, zero mutable globals, and O(log N) in-place lookup.
  - Supports normal rules, wildcard rules (`*.ck`, `*.mm`, `*.kobe.jp`), exception rules (`!www.ck`, `!city.kobe.jp`), IP literal detection (`is_ip_address`, including trailing-dot IPv4 rejection), RFC 1035 host/label length bounds (253/63 octets), UTS #46 separator/case/fullwidth canonicalization with fail-closed rejection of non-NFKC/combining Unicode code points (`src/unicode_noncanon.pion`, generated by `packages/cookie/scripts/gen_unicode_noncanon.py`), and built-in RFC 3492 Punycode encoding so both Unicode IDN (`食狮.公司.cn`) and ASCII Punycode (`xn--85x722f.xn--55qx5d.cn`) domains resolve identically.
  - APIs: `public_suffix`, `public_suffix_icann`, `public_suffix_info`, `registrable_domain`, `registrable_domain_icann`, `is_public_suffix`, `is_public_suffix_icann`.
- **RFC 6265bis `CookieJar` with CHIPS & Eviction (`src/jar.pion`)**:
  - Policy-enforcing `store_set_cookie` / `store_cookie`: input injection validation, domain-match (`Cookie::with_domain` expects a domain without a leading `.`; passing a leading `.` returns `DomainMismatch` because only `parse_set_cookie` strips a single leading `.` per §5.6.3), PSL rejection (blocks setting cookies on public suffixes like `co.uk` / `github.io`), `HttpOnly` API isolation, `Secure` origin isolation & "leave secure cookies alone" (§5.7 step 16), `(name, domain, host_only, path, partition_key)` identity (§5.7 step 23), cross-site `SameSite` write guard (§5.7 step 18), `SameSite=None` requires `Secure`, CHIPS `Partitioned` keying by normalized `top_level_site`, and `creation_time` preservation on update.
  - `matching_cookies` / `cookie_header`: domain-match, path-match, expiry filtering, `Secure`/`HttpOnly`/`SameSite` (`Strict`/`Lax` HTTP top-level safe navigation/`None`), CHIPS partition matching, and RFC 6265bis §5.8.3 ordering (longest `Path` first, then earliest `creation_time`).
  - Deterministic O(N) eviction under per-site (eTLD+1) and global limits (expired first, then non-`Secure`, then oldest `last_access_time`), O(N) `purge_expired` and `clear_domain`, `clear`, and atomic, strictly validated `export_text` / `import_text` (escaping sentinel `partition_key` values, deduplicating by identity, and enforcing `JarLimits`).

## Usage

```pion
import "cookie"

let jar = cookie::CookieJar::new()
let ctx = cookie::RequestContext::new(
  "https://embed.example.co.uk/app/view",
  Some("https://top-site.example"),
  true,  // is_http_api
  false, // is_same_site
  1700000000L,
)
let _ = jar.store_set_cookie(
  "__Host-sid=abc; Secure; Path=/; SameSite=None; Partitioned",
  ctx,
)
let header = jar.cookie_header(ctx)
let reg = cookie::registrable_domain("www.city.kobe.jp") // Some("city.kobe.jp")
```
